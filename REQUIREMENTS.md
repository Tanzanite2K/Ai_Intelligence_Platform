# REQUIREMENTS — assessment → implementation map

The specification is *AI Engineer (Demo Task), GraphOne / FrontierAtlas, Nov 2026*. Every requirement is listed below with the module that implements it and the test that proves it. Verification status and evidence are in [REQUIREMENTS_TRACEABILITY.md](REQUIREMENTS_TRACEABILITY.md).

## Evaluation weights → where to look

| Category (weight) | Primary modules | Primary tests |
|---|---|---|

## Phase I — massive one-time acquisition
- **R1.1** Highly concurrent scraper for large directories → `core/http.py` (pooled aiohttp, global semaphore, per-domain buckets), `pipelines/ingestion.py` (`run_many`), Celery fan-out in `pipelines/tasks.py`.
- **R1.2** Research papers from arXiv + Papers with Code, correlated with GitHub repos, with current stars → `crawlers/research/sources.py` (arXiv Atom API; Hugging Face Papers, which replaced Papers with Code in 2025), `crawlers/research/github.py` (live `stargazers_count`, ETag, rate-limit aware), `crawlers/research/crawler.py`.
- **R1.3** Scales to 500k+ with infrastructure changes only → work units per source/page, stateless workers, idempotent upserts, checkpoints; `docs/benchmarks.json`.
- **R1.4** ≥1,000 startups / products / papers (with GitHub metrics) → `crawlers/startups/{yc,huggingface_orgs}.py`, `crawlers/products/{huggingface,producthunt}.py`, research crawler (`require_github=True`).

## Phase II — high-fidelity signals
- **R2.1** 5 news sources + 5 job boards → `crawlers/news/rss.py` (TechCrunch, VentureBeat, The Verge, MIT Tech Review, Ars Technica); `crawlers/jobs/boards.py` (Greenhouse, Ashby, Lever, RemoteOK, Himalayas).
- **R2.2** Guaranteed ≤24 h → `core/dates.py::FreshnessPolicy` (precision-aware) + export-time re-check in `exports/tabs.py`.
- **R2.3** Full-text content → `core/text.py::extract_main_text`, RSS `content:encoded`, article fetch.
- **R2.4** Date normalisation, relative dates, missing meta tags → `core/dates.py` (`parse_relative`, `parse_datetime`, `extract_publication_date`).
- **R2.5** Heuristic when a source lacks dates ("new since last run") → `core/dates.py::new_since_last_run`, `crawlers/fresh.py`.
- **R2.6** No duplicate processing across workers → `core/dedup.py` (Redis claim/lease/done) + DB unique constraint.

## Phase III — LLM extraction
- **R3.1** Gemini Flash → Groq Llama → DeepSeek fallback → `extraction/providers/vendors.py`, `orchestrator.py`.
- **R3.2** Chunking that prevents 413 while keeping dense content → `extraction/chunking.py`; 413 recovery by bisection in `orchestrator.py`.
- **R3.3** 429 with exponential backoff + jitter → `core/retry.py::backoff_delay` (full jitter), `Retry-After`/`retryDelay` parsing, token-bucket penalty.
- **R3.4** Structured JSON, Pydantic validation, no hallucination → evidence-grounded `validators.py`, typed coercion, confidence, validation status.

## Phase IV — entity resolution
- **R4.1** "OpenAI", "OpenAI, Inc.", "Open AI" → "OpenAI" → `entity_resolution/resolver.py`.
- **R4.2** Seed of ≥50 known AI companies → `entity_resolution/seed.py` (60).
- **R4.3** Entity mapping log (raw vs canonical) → `Resolution.to_mapping`, `entity_mappings` table, export tab.

## Phase V — anti-bot and scale
- **R5.1** asyncio + aiohttp / Playwright async → `core/http.py`, `core/browser.py`.
- **R5.2** Strategy for Cloudflare / JS-heavy / aggressive blockers → detection in `core/http.py::detect_challenge`; policy in `architecture.pdf` and README.

## Phase VI — architecture document
- **R6.1–R6.4** Scale, 413/429, freshness/dedup, storage → `architecture.pdf` (3 pages) generated by `scripts/build_architecture_pdf.py`.

## Schemas
- **S1–S4** STARTUP / PRODUCT / RESEARCH_PAPER / JOB exactly as specified; NEWS designed analogously → `core/schemas.py`.

## Deliverables
- **D1** Google Sheet with 6 tabs → `exports/google_sheets.py` + `exports/tabs.py`; CSV fallback `exports/csv_export.py`.
- **D2** Repository with README, `src/`, `architecture.pdf` → this repo.
